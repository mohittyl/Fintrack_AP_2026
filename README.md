# Fintrack AP 2026

Fintrack is a personal finance tracking project focused on recording income and expenses, organizing transactions by account and category, and keeping the underlying data structured and consistent.

## Database design

The `dbms/` folder contains the normalization work for Fintrack, from the initial transaction record through 1NF, 2NF, and 3NF.

## Data covered

- Users and their accounts
- Income and expense transactions
- Categories used to organize transactions

The database design is documented here as part of the project work.
